ATLAS PRESTIGE RENT CAR – Structure du site
===========================================

Créez un dossier, par exemple : atlas-prestige-rent-car/
et placez-y les fichiers exportés :

atlas-prestige-rent-car/
  |-- index-fr.html   (site en français)
  |-- index-ar.html   (site en arabe)
  |-- index-en.html   (site en anglais)
  |-- README.txt

MISE EN LIGNE
-------------
1. Renommez la langue principale en index.html (ex : index-fr.html -> index.html).
2. Hébergez le dossier sur n'importe quel hébergeur (Netlify, Hostinger, OVH, GitHub Pages…).
3. Les langues sont accessibles via le sélecteur 🌐 dans l'en-tête (persistant).
